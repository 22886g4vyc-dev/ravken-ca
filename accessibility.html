Accessibility

Accessibility on this site

We want everyone to be able to read this site and reach us through it.

Our standard

ravken.ca is built to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. The site is hand-written HTML with no page builder, which keeps the structure simple and predictable.

What the site does

  • Every page has one main heading and a logical heading order.
  • All images carry descriptive alternative text; decorative graphics are hidden from screen readers.
  • Navigation, buttons, map pins and forms work with a keyboard, and the focused element is always visible.
  • Form fields are labelled, and status messages are announced to assistive technology.
  • Text and background colours meet contrast requirements, and the page reflows to a single column on small screens without horizontal scrolling.
  • Motion is reduced for visitors whose system asks for it.

Known limitations

The project map on the About page is an illustration. The same projects and towns are named in the page text and in each pin's label so nothing depends on seeing the map.

Tell us if something does not work

If any part of this site is hard to use, email chaz@ravken.ca. We will fix what we can and send you the information another way in the meantime.
